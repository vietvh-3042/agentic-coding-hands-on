# Deployment

## Platform: Vercel

## URL: https://agentic-coding-hands-on-mu.vercel.app

## Deploy Command

```bash
pnpm dlx vercel@latest deploy --prod
```

## Environment Variables

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_LAUNCH_AT`
- `SUPABASE_AUTH_GOOGLE_CLIENT_ID`
- `SUPABASE_AUTH_GOOGLE_SECRET`

## Custom Domain

No custom domain configured. Add one from the Vercel project settings and update DNS as instructed by Vercel.

## Rollback

```bash
pnpm dlx vercel@latest rollback https://agentic-coding-hands-2ulwbab3a-vuhongvietsunasterisks-projects.vercel.app
```
